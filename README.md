# PrettyLogs

Удобный просмотрщик логов для **OpenLens** (Lens 6.3+): фильтрация по уровню, поиск по regex, сохраняемые наборы фильтров, подсветка синтаксиса, pretty-вид JSON / XML / YAML и других форматов, а также отдельное окно с логами в реальном времени.

## Установка

1. В OpenLens откройте **Extensions** (`Ctrl+Shift+E`).
2. В поле **Name or file path or URL to an extension package** вставьте ссылку и нажмите **Install**:

```
https://github.com/Crazymoralfreak/PrettyLogs/releases/latest/download/prettylogs.tgz
```

Конкретную версию можно поставить по ссылке вида
`https://github.com/Crazymoralfreak/PrettyLogs/releases/download/v0.1.0/openlens-prettylogs-0.1.0.tgz`.

После установки расширение включается автоматически. Если пункты меню не появились, перезапустите OpenLens.

## Как открыть логи

- Контекстное меню (или иконка в панели) у **Pod, Deployment, StatefulSet, DaemonSet, ReplicaSet, Job**:
  - **Pretty Logs** открывает вкладку на странице *Pretty Logs* в боковом меню кластера;
  - **Pretty Logs в окне** открывает отдельное окно.
- Для workload-ов показываются логи всех его подов сразу, строки объединяются по времени, у каждой есть цветная метка пода и контейнера. Новые поды (например, после рестарта) подхватываются автоматически.

## Возможности

- **Уровни логирования.** Переключатели TRACE / DEBUG / INFO / WARN / ERROR / FATAL с счётчиками. Двойной клик оставляет один уровень, кнопка `≥ WARN` показывает только проблемы. Уровень определяется по JSON-полям (`level`, `severity`, `@l`, числовые уровни pino/bunyan), префиксам klog, `level=...` (logfmt) и по тексту строки.
- **Поиск.** Обычный текст или regex, учёт регистра, инверсия, режимы «только совпадения» и «подсвечивать все», переход по совпадениям (`Enter` / `Shift+Enter` / `F3`), `Ctrl+F` для фокуса на поиске.
- **Правила фильтрации.** Несколько правил одновременно: «Показать» (ИЛИ между правилами), «Скрыть» и «Подсветить» своим цветом.
- **Наборы фильтров.** Уровни, поиск и правила сохраняются под именем, применяются в один клик, экспортируются и импортируются как JSON.
- **Pretty-вид.** Строки со структурированными данными помечаются бейджем (JSON, XML, YAML, TOML, logfmt, SQL). Развернув строку (или включив «Pretty» для всех), вы увидите отформатированный и подсвеченный фрагмент с переключателем Pretty / Raw и копированием. JSON, вложенный в строковые значения, раскрывается автоматически.
- **Подсветка строк.** Время, уровень, строки в кавычках, числа, URL, IP, UUID, ключи `key=value`.
- **Многострочные записи.** Stack trace и pretty-printed блоки склеиваются с родительской строкой.
- **Отдельное окно.** Кнопка «В окно» переносит просмотр в независимое окно, которое обновляется в реальном времени, имеет те же фильтры и может быть закреплено поверх остальных окон. Окно работает, пока открыт кластер в Lens.
- **Управление.** Выбор подов и контейнеров (включая init), логи предыдущего контейнера, диапазон (последние N строк или за период), пауза, очистка, скачивание отфильтрованного результата, перенос строк, время в UTC или локальное.

## Настройки

*Preferences → Pretty Logs*: интервал обновления, число строк при открытии, размер буфера, склейка многострочных записей.

## Как работает «реальное время»

Lens API отдаёт логи запросом, а не потоком, поэтому расширение опрашивает Kubernetes API (по умолчанию раз в 1,5 с) с `sinceTime` и отсекает уже полученные строки по временной метке.

## Выпуск версии

Релиз создаётся автоматически: при пуше тега `vX.Y.Z` (версия должна совпадать с `package.json`) GitHub Actions собирает расширение и прикладывает к релизу файлы `prettylogs.tgz` (стабильное имя для ссылки установки) и `openlens-prettylogs-X.Y.Z.tgz`.
